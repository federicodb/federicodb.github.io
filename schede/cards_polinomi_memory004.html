Palestra: Memory delle Scomposizioni

Gioco Memory per allenare il riconoscimento dei prodotti notevoli e delle scomposizioni (Raccoglimento, Quadrati, Trinomi).

Ripasso

Il memory delle scomposizioni allena a riconoscere a colpo d'occhio la forma di un polinomio: differenza di quadrati, quadrato di binomio, trinomio, raccoglimento. Riconoscere la forma è metà del lavoro.

Regole

  • $a^2 - b^2 = (a - b)(a + b)$
  • $a^2 + 2ab + b^2 = (a + b)^2$
  • $x^2 + sx + p$: somma $s$, prodotto $p$

Competenze (Riforma 2017)

  • CIT_5 Imparare a imparare
  • MAT_K1 Insiemi numerici e calcolo letterale

  2. Scomponi $x^2 + 10x + 25$.
